# Periódico Escolar San Luis Gonzaga

Este es el repositorio oficial del proyecto **Periódico Escolar San Luis Gonzaga**, una plataforma web desarrollada para publicar y gestionar noticias, eventos y proyectos de la comunidad educativa. El sitio incluye tanto una vista pública para los lectores como un panel de administración para la gestión de contenido.

## 🚀 Características

- **Portal de Noticias:** Publicación de artículos, noticias y eventos relevantes del colegio.
- **Gestión de Proyectos:** Sección dedicada a los proyectos escolares y actividades.
- **Panel de Administración:** Interfaz privada para que administradores puedan crear, editar y eliminar noticias y proyectos.
- **Sistema de Login:** Autenticación para administradores con credenciales predefinidas.
- **Buscador Integrado:** Funcionalidad de búsqueda para encontrar noticias fácilmente.
- **Diseño Responsivo:** Interfaz adaptable a computadoras y dispositivos móviles.

## 🛠️ Tecnologías Utilizadas

- **Backend:** PHP
- **Frontend:** HTML5, CSS3, JavaScript
- **Base de Datos:** MySQL
- **Servidor Local:** XAMPP (Apache + MySQL + PHP)
- **Entorno de Desarrollo:** Visual Studio Code
